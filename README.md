# github_auth

### Requirements

- Node.js 20+ and npm

### Getting started

```bash
Run the following command on your local environment:
git clone https://github.com/mm19810/github_auth.git
cd github_auth
```

## Environment Variables
Add the following environment variables in .env
```bash
NEXT_PUBLIC_API_URL=
```

## Installation (Dependencies)
```bash
yarn
```

## NPM Scripts

### Running Dev Server
```bash
PORT=8080 yarn dev
```
